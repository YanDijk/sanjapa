# Sanjapa Prime Launch

Crie uma landing page moderna, sofisticada e altamente profissional para um restaurante japonês premium chamado **Sanjapa Prime Sushi**.

IMPORTANTE: O objetivo é criar uma versão muito mais moderna e visualmente impactante do site atual do restaurante, mantendo a identidade de gastronomia japonesa sofisticada, porém com design premium, responsivo e focado em conversão.

## ESTILO VISUAL

Crie um design elegante inspirado em restaurantes japoneses de alto padrão.

Paleta de cores:

* Preto profundo como cor principal
* Vermelho escuro japonês para detalhes e CTAs
* Dourado discreto para elementos premium
* Branco/cinza claro para textos secundários

Utilize:

* Muito espaço negativo
* Tipografia elegante e moderna
* Animações suaves ao rolar a página
* Efeito glassmorphism sutil em alguns cards
* Hover effects sofisticados
* Imagens grandes e impactantes de comida japonesa
* Gradientes escuros sobre imagens para melhorar legibilidade
* Design minimalista e luxuoso

A experiência deve transmitir: **exclusividade, gastronomia premium, sofisticação e autenticidade japonesa**.

# REQUISITOS TÉCNICOS

* Site completamente responsivo para celular, tablet e desktop
* Mobile-first
* Animações suaves utilizando Framer Motion
* Scroll suave entre seções
* Navbar responsiva com menu hamburger no mobile
* Botões com microinterações
* Lazy loading para imagens
* SEO básico configurado
* Performance otimizada
* Componentização limpa
* Código organizado
* Utilizar React + Tailwind CSS
* Utilizar ícones modernos do Lucide React

IMPORTANTE:

Não criar um site genérico de restaurante.

O design precisa parecer o site de uma marca consolidada e premium de gastronomia japonesa.

Priorizar impacto visual, imagens grandes, sofisticação, minimalismo e conversão para pedidos.

Criar uma experiência cinematográfica, com transições suaves e elementos que transmitam luxo e exclusividade.

Os links de WhatsApp, cardápios, Instagram, Facebook e tour virtual devem estar organizados de forma fácil para alteração posterior.

Utilizar dados reais das unidades apenas como conteúdo inicial, mas estruturar o projeto para que todas as informações possam ser facilmente editadas.
